# Docs

Start here:
- `getting-started.md`: from template to your first digest.
- `call-the-agent.md`: call Axon from an agent over A2A or MCP (Tier 1, 2 and 3).
- `../ARCHITECTURE.md`: overview of the four repositories. Each code repo has its own `ARCHITECTURE.md`.
- `../demo/`: `demo-script.md` and `qa-prep.md` for presenting the project.

Specification and state:
- `axon-architecture.md`: **the specification and the single source of truth** (v1.7 plus Appendix C).
  Changes go through an Appendix C item.
- `axon-STATE.md`, `axon-GUIDELINES.md`: handoff state (what is verified live) and engineering rules.

Setup:
- `setup-telegram.md`, `setup-slack.md`, `features.md` (Atom, embeddings, trends, feedback), `onboarding.md`.

Operations:
- `repo-hardening.md`, `pinning-actions.md`, `npm-audit.md`, `notices-review.md`, `source-discovery.md`.
- The feed's first-push checklist lives in the `axon-feed` repo (`docs/go-live.md`).
- The gateway's deploy and GitHub App guides live in the `axon-gateway` repo
  (`docs/deploy.md`, `docs/github-app-setup.md`).
